# AnCar Global Leads Finder

Sistema de prospección comercial de AnCar para encontrar, calificar y gestionar negocios potencialmente interesados en los sistemas AnCar.

## Objetivo inicial

Prioridad: tiendas y negocios de celulares que financian smartphones y pueden necesitar MDM, bloqueo, localización y gestión de cartera.

## Flujo

Prospectar → enriquecer → puntuar → clasificar → contactar → seguimiento → demo → cierre.

## Principios

- No inventar datos de prospectos.
- Separar datos verificados de datos pendientes de verificación.
- Usar únicamente información pública o fuentes autorizadas.
- Registrar fuente y fecha de cada dato.
- No enviar mensajes automáticamente sin una integración y autorización explícitas.
